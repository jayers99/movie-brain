## Builder's pages

### Decisions (agent defaults unless marked)

| Decision | Status |
|---|---|
| **The verb.** `movie-brain viewings add (--title TITLE [--year YYYY] \| --film ID) [--on YYYY-MM-DD] [--service SLUG] [--rate N] --text -` reads the dictation on stdin and writes, in ONE transaction: a `viewing` row (film, `watched_on` = `--on` or today, `service`, `logged_on`), an `artefact` row (kind `dictation`, the text whole), the 0–10 through the existing `rate_film` when `--rate` is given, and clears `unseen` (through `set_unseen(False)`, which touches nothing else). One line out: `LOGGED  #ID 'Title' (Year) · date · service · viewing #V · <how matched> · rated N`. Exit 0 | owner ruled the shape (dictation → command), the flags are the agent's |
| **The ladder lives in the verb, not in the prompt.** `--title` is resolved: (1) the film the dashboard has open, when its normalised title equals the given one (and `--year`, if given); (2) else the catalogue films whose `title_norm` equals the given title (and year): exactly one → that film; (3) else `AMBIGUOUS` with the candidates listed (`#id  title (year)  director  best source`) or `NO-FILM`, exit 3, nothing written. `--film ID` skips the ladder. Normalisation is `norm_title` (case, accents, straight/curly apostrophes, punctuation) — Pandora’s Box is found by "Pandora's Box" | owner ruled the ladder 2026-09-27; walked in stories 1–4 |
| **The open-film signal.** `app.js` tells the server when the drawer opens and closes (`PUT /api/drawer {film_id \| null}`); the server keeps it in `meta` under `drawer_film`; the verb reads it, and `viewings open` prints it. A stale value (browser closed with a film open) can only ever pick among films of the SAME title, so it cannot log the wrong work; no expiry. Dashboard not running → no signal, ladder starts at rung 2 | agent default, walked in stories 2 and 3 |
| **One viewing per film per day; many artefacts.** `UNIQUE(film_id, watched_on)`; a second `add` for the same film and date appends an artefact to the existing viewing (`ADDED-TO  viewing #V … · note N`), moves the rating if `--rate` is given, sets the service if the row had none. A different date is a new viewing | agent default, walked in stories 5 and 8 |
| **Rating rule.** `--rate` only when the dictation states a whole number 0–10; a range or a word is a question back to the owner; no number → no write, the standing rating stays | owner: 0–10 stays per film (2026-09-20); the "number said" rule is the agent's, walked in story 5 |
| **Tier, rank, documentaries.** The log never places a film; "put it in tier N" gets the drawer's Tier row / Rank this named back, nothing written. Tier calibration (§3.2) is a named follow-up. The documentaries pool (§3.3) stays open | agent default, walked in story 6 |
| **Service.** `--service` is a registry slug (`movie_service.slug`, validated; unknown → `REFUSED`, exit 2) or omitted; a disc or a cinema is "omitted" — no pseudo-service is added.
