What you should know before saying yes

  • One mark, one meaning. study on a viewing's line means: there is a technique here to watch for a second time. It is not "I liked it" (that is the rating) and not the 2004–08 Rewatch chip (5★ then, unrated since), which is untouched and keeps its name.
  • Two ways to set it, both from a sentence to me. A dictation that names a reason to go back sets it on the viewing it logs: viewings add … --study (story 2; the same flag marks last night's line when you add to it with --on, story 7). A past line is marked by its number: viewings study VID (story 1) — I read the number off viewings list --film ID first. viewings study VID --off clears it (story 5). A number that is not a line is refused and nothing is written; marking a marked line, or clearing a clear one, answers already marked / already clear and changes nothing (story 6).
  • I never infer it from praise. "Still perfect, I'd watch it any day" is a viewing with no mark and no question (story 3). "Worth a rewatch for…", "need to watch again to see how…", "pay closer attention next time to…", "mark it for study" set it. A sentence that could go either way gets one yes-or-no question before anything runs.
  • The mark lives on the viewing, not on the film. A film is "to study" when any of its lines is marked. A second viewing of the same film writes its own line and touches no other — the mark stays until you clear it (story 5). Removing a viewing takes its mark with it; removing one note does not (story 9).
  • Where you see it. In the drawer, the word on the line, after the service and before your note; nothing to click. In the chip row, Watched now cycles: off → Watched → To study → off, the way Reachable, Rated, Criterion and Owned already do — the third state lists the films with a marked line, newest viewing first, and reads Nothing marked for study yet when there are none (story 4). No badge in the film's row, no new column. At the keyboard, viewings list --study.
  • The page refreshes itself when you come back to it after a command, as it does for a dictation today: the drawer re-reads the open film on focus, so the mark shows without a reload (story 1). A reload shows the same — the mark is in the database.
  • Storage: one column on the viewing table (migration 032, applied live only with your yes). No new table, no free-text tags, no tier or rank effect, no change to the rating, the watchlist or Unseen. Backlog 5 (the notes and criticism loop) is where the second watch's analysis will land — this mark is the bookmark for it.
  • Failure: a refused command writes nothing. If the dashboard is not running the mark still lands (it is a database fact) and the page reads it on its next open.
