# Move on (backlog 44) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When an edit inside the drawer (a rating, the ★, the ♡) drops the open film out of the filtered list, the drawer moves on to the film now at its index exactly as ↓ would have, and the moved-to drawer carries one grey line — "Wishlisted Pan's Labyrinth · Undo" — that reverses the last edit.

**Architecture:** One client-side function in `static/app.js`, `moveOnIfLeft(edit)`, called on the three edit paths only (never inside `applyFilters`), reusing `openIndex` (already kept by `trackOpenIndex`) and `moveDrawerTo` (the same path ↑ ↓ and a row click take, so history stays "one Back closes"). A module variable `movedOn` remembers the last edit that moved the drawer; `openDrawer` draws the line when it redraws the line's own film and clears it otherwise; one delegated click handler performs the exact reverse API call and applies the landing rule. No server, schema or API change.

**Tech Stack:** vanilla JS in `src/movie_brain/web/static/app.js`, CSS in `static/app.css`, Playwright (`pytest`, `tests/web/`) against a seeded Flask app with the `FakeAccount` / `FakePrices` wishlist fakes from `tests/web/conftest.py`.

**Spec:** `docs/superpowers/briefs/2026-09-24-move-on/brief.md` (version 1.0, the owner chose variant B). Mock-up: `mockup-1.html` beside it. Trial log: `trial-log.md` beside it.

## Global Constraints

- The trigger is the EDIT, never the filter: `applyFilters()` is not modified; chips, the search box, the list picker, the column filters and popstate must still leave the gap (find-my-row story 6, `tests/web/test_find_my_row.py::test_story_6_the_awkward_one_my_marked_film_leaves_the_list` must keep passing unchanged).
- The move IS a step: `moveDrawerTo(i)` → `openDrawer(id, 'step')`. Never call `openDrawer(id, 'keep')` or `'push'` for a move — 'keep' clears `drawerOpenPushed` and breaks "one Back closes".
- At the end of the list, the film before: `min(openIndex, state.filtered.length − 1)`. A film that was never in the list (`openIndex == null`) stays put. An empty list moves nothing and the drawer stays open.
- Only the LAST edit has an Undo, only in the drawer it moved to; the line lasts until that drawer is redrawn (a step, a row click, a close, Back, reload).
- Landing rule: when the reverse call lands, the film's row comes back at once (the reverse patches `state.films` and calls `applyFilters()`); the drawer goes back to the film ONLY if the owner has not stepped away, clicked another row or closed since pressing Undo. A ↓ then ↑ back counts as stepping away (the line's memory is cleared by any other draw).
- A failed wishlist Undo keeps the line's words and puts "Couldn't reach CheapCharts. Try again" where Undo was; Try again repeats the reverse call only. A failed rating or star Undo shows the existing toast and the line keeps its Undo.
- Copy, verbatim: labels `Wishlisted <title>` / `Took <title> off your wishlist` / `Rated <title> <n>` / `Cleared <title>'s rating` / `Starred <title>` / `Took <title> off your watchlist`; the button `Undo`, busy text `Reaching CheapCharts…`, failure `Couldn't reach CheapCharts.` + button `Try again`.
- Standing dashboard taste: filled means active, no glyphs, nothing else on the page moves; the line is grey (`var(--chip)`), one line, under the title.
- Tests never reach a real account: every server fixture takes `WishlistGateway(FakePrices(), account)` with a fresh `FakeAccount()`. No schema, no API, no live-database step. Ruff and mypy clean; the whole suite green (`uv run pytest`, about 40 s).
- Branch `feature/STORY-44-move-on` from `main`. Commit messages: one line, the why. Never merge or push without the owner's separate yes.

```js
  // ---- Move on (brief docs/superpowers/briefs/2026-09-24-move-on/brief.md) ----
  // After a drawer EDIT has landed (a rating, the ★, the ♡ — the three edits a filter reads), if
  // the open film is no longer in the shown list, take the step ↓ would have taken: to the film
  // now at its index, or the one before at the end. Called on the edit paths ONLY — never from
  // applyFilters — so a chip, the search, the list picker, a column filter or Back still leave
  // the gap (find-my-row story 6). A film that was never in the list (openIndex null) stays put;
  // an empty list moves nothing. `edit` is what the moved-to drawer's undo line remembers.
  let movedOn = null;  // { at, film, label, slow, undo } — the last edit that moved the drawer on
  function moveOnIfLeft(edit) {
    if (drawer.hidden || openIndex == null) return false;
    if (state.filtered.some((f) => f.id === state.openFilm)) return false;
    if (!state.filtered.length) return false;
    const i = Math.min(openIndex, state.filtered.length - 1);
    movedOn = { ...edit, at: state.filtered[i].id };
    moveDrawerTo(i);
    return true;
  }
```

```js
  // The line under the moved-to drawer's title: "Wishlisted Pan's Labyrinth · Undo". Only the
  // LAST edit has one; it lasts until that drawer is redrawn (openDrawer clears it for any other
  // film, hideDrawer always). A failed wishlist Undo keeps the words and offers Try again in
  // Undo's place; a failed rating or star Undo toasts (inside edit.undo) and keeps its Undo.
  function movedOnHtml(failed = false) {
    return `<div class="moved-on">${esc(movedOn.label)} ·${failed ? ' <span class="wish-failed">Couldn\'t reach CheapCharts.</span>' : ''} <button class="undo">${failed ? 'Try again' : 'Undo'}</button></div>`;
  }
  body.addEventListener('click', async (e) => {
    const b = e.target.closest('.moved-on button.undo'); if (!b || b.disabled || !movedOn) return;
    const m = movedOn;
    b.disabled = true; if (m.slow) b.textContent = 'Reaching CheapCharts…';
    const ok = await m.undo();  // the exact reverse call; on success the film is back in state.films and the list
    const line = body.querySelector('.moved-on');
    if (!ok) { if (line && movedOn === m) line.outerHTML = movedOnHtml(m.slow); return; }
    // Landing rule: the row is back already; the drawer goes back to the film only if nothing was
    // stepped, clicked or closed since Undo was pressed (any other draw cleared movedOn).
    if (movedOn !== m || drawer.hidden || state.openFilm !== m.at) return;
    movedOn = null;
    const i = state.filtered.findIndex((f) => f.id === m.film);
    if (i >= 0) moveDrawerTo(i); else if (line) line.remove();
  });
```
